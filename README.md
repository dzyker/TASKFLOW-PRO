# 📋 TaskFlow Pro

Современное веб-приложение для управления задачами с красивым интерфейсом и полной адаптивностью для всех устройств.

## ✨ Особенности

- ✅ **Создание и управление задачами** - легко добавляйте, редактируйте и удаляйте задачи
- 🎯 **Система приоритетов** - устанавливайте приоритет от 1 до 4 для каждой задачи
- 🔄 **Гибкая сортировка** - сортируйте задачи по приоритету, статусу или дате (по возрастанию/убыванию)
- 🔍 **Фильтрация** - просматривайте все задачи, только выполненные или только невыполненные
- 📝 **Описания задач** - добавляйте подробные описания к вашим задачам
- 📱 **Полностью адаптивный дизайн** - отлично работает на мобильных устройствах, планшетах и десктопах
- 🎨 **Современный UI** - красивый интерфейс с эффектами размытия и теней
- ⚡ **Быстрая работа** - оптимизированное приложение на React 19 и Vite

## 🚀 Быстрый старт

### Требования

- Node.js (версия 18 или выше)
- npm или yarn

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd "TaskFlow Pro"
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите dev-сервер:
```bash
npm run dev
```

4. Откройте браузер и перейдите по адресу, указанному в терминале (обычно `http://localhost:5173`)

## 📦 Сборка для продакшена

```bash
npm run build
```

## 🎮 Использование

### Создание задачи

1. Введите название задачи в поле ввода
2. Нажмите кнопку "Submit" или Enter
3. Задача будет создана с приоритетом 4 (низкий) по умолчанию

### Редактирование задачи

1. Кликните на задачу, чтобы развернуть её
2. Нажмите кнопку редактирования (иконка карандаша)
3. Измените название и/или описание
4. Нажмите "Change" для сохранения

### Изменение приоритета

1. Кликните на цветной кружок с номером приоритета
2. Выберите новый приоритет из появившихся вариантов
3. Приоритеты: 1 (высокий, красный) → 4 (низкий, синий)

### Изменение статуса

- Кликните на чекбокс слева от задачи, чтобы отметить её как выполненную
- Повторный клик вернёт задачу в статус "Невыполненная"

### Сортировка задач

- Выберите критерий сортировки: **Priority**, **Status** или **Date**
- Используйте кнопки со стрелками для изменения направления сортировки (↑ по возрастанию, ↓ по убыванию)

### Фильтрация задач

- Кликните на индикатор фильтра вверху списка задач
- Переключайтесь между: **All Tasks**, **Completed Tasks**, **Uncompleted Tasks**

### Удаление задачи

1. Разверните задачу
2. Нажмите кнопку удаления (иконка крестика)
3. Задача будет удалена безвозвратно

## 🎨 Адаптивность

Приложение полностью адаптировано для всех размеров экранов:

- **Мобильные устройства** (< 640px) - вертикальная компоновка, компактные элементы
- **Планшеты** (640px - 1024px) - промежуточные размеры
- **Десктопы** (> 1024px) - горизонтальная компоновка, полный функционал

## 📝 Типы данных

### Task

```typescript
interface Task {
  id: Crypto;           // UUID задачи
  date: Date;           // Дата создания
  title: string;        // Название задачи
  status: string;       // "Completed" | "Uncompleted"
  priority: number;     // 1-4 (1 - высший, 4 - низший)
  description: string;  // Описание задачи
}
```
